`menu_context` names the record so a screen reader announces which row the menu belongs to instead of reading eight identical "Ações" buttons. `menu_scope` + `menu_key` build the trigger id (`acoes---trigger`) so the panel can point at it with `aria-labelledby` — a `role="menu"` needs its own accessible name. They are two variables and not one concatenated string because Django's `add` filter returns an empty string when joining text to an integer pk. Menu items carry `tabindex="-1"`: the ARIA menu pattern moves between items with the arrow keys (handled in `static/js/app.js`), while `Tab` leaves the menu instead of walking through every entry. The 44px square keeps the touch target above the 40px floor. {% endcomment %}
